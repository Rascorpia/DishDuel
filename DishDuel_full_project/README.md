# DishDuel

Красивое веб-приложение-игра: выбираешь лучшее блюдо через дуэли, а в конце открывается подробный рецепт победителя.

## Запуск в GitHub Codespaces

```bash
npm install
npm run dev
```

Открой порт 5173 в браузере.

## Что внутри

- 50 рецептов
- локальные изображения блюд в `public/images`
- вкладка управления блюдами
- добавление своих блюд
- отключение блюд из турнира
- режим турнира и режим каждый-с-каждым
- анимации Framer Motion
- конфетти в финале
- сохранение пользовательских настроек в localStorage
